# Hap pas Hapi

Aplikacion celular për mësimin e gjuhës gjermane në shqip.

## Nisja

1. Instalo Node.js 20 ose më të ri.
2. Në këtë dosje ekzekuto `npm install`.
3. Ekzekuto `npx expo start`.
4. Skano kodin QR me aplikacionin Expo Go në Android ose iPhone.

Versioni fillestar përmban nivelet A1–C2, mësim demonstrues, shqiptim me audio,
kuiz, pikë, seri ditore dhe progres.
